# Проверка VoicePaste 1.1.0-beta

Дата: 2026-10-03. Среда: Windows x64, Python 3.12.3, PySide6 6.10.2. Реальное пользовательское окно для вставки автоматически не проверялось.

## Выполнено

1. 16 тестов: таймаут и повтор Gemini, отказ при ошибке авторизации, WAV и обработка записи, очередь Qt для GUI, запрет параллельной обработки, отмена настроек, ошибка хранилища ключа, Unicode/SendInput, регистрация и повторное включение Win32 hotkey.
2. В тесте цепочки настоящий внутренний код проходит запись → WAV → аудиочасть Gemini → текст → вставку. Микрофон, ответ API, буфер и нажатие клавиши в этом тесте подменены; это проверка логики, а не реальной диктовки.
3. Реальный вход микрофона записал за 2 секунды WAV: 21 216 кадров, 16 кГц, mono, PCM 16 bit. Запись осталась в памяти, в API не отправлялась.
4. Существующий ключ в Windows Credential Manager позволил запросить метаданные сохранённой модели `gemini-2.5-flash-lite`.
5. Реальный API распознал синтетическую русскую фразу за 3 225 мс. Основной текст совпал, название VoicePaste распознано как «Voice & Pest». Это один запрос, не измерение средней скорости и не проверка речи пользователя.
6. Диагностическая и финальная EXE после исключения посторонней ICU запустились в отдельных профилях: журнал подтвердил включение hotkey, процессы продолжали работать через 10 секунд. Финальная сборка выполнена через `build.ps1`, версия 1.1.0-beta. Старый EXE сохранён в `dist/`. Authenticode-подпись отсутствует.
7. Документированный `run.ps1` запущен из другого рабочего каталога: приложение загрузило тестовый профиль и включило hotkey. Все тестовые процессы завершены; личная конфигурация не изменена.

SHA-256 финальной EXE: `62482A6CDC0EAFB155CE1B5DBCCDFA11D208A6B8C63734C4173FD5BF2586DAB3`.

## Ручной сценарий — подтверждён пользователем 2026-10-04

1. Запустить `release/VoicePaste.exe`, открыть обычный Блокнот и поставить курсор в пустой документ.
2. Удерживая настроенное сочетание (по умолчанию Ctrl+Shift), произнести короткую фразу и отпустить клавиши.
3. Проверить появление текста, затем повторить запись. Если текст не появился, посмотреть `voicepaste.log` в каталоге журналов из README.

Пользователь сообщил, что полный путь работает; 3.8 отвечает слишком долго. Это подтверждение пользовательского сценария версии 1.1.0-beta. Чистая установка на другом компьютере и вставка в программы с повышенными правами отдельно не проверены.

## Ускорение 1.1.2-beta — 2026-10-04

26 тестов прошли, включая проверку допустимых уровней/бюджетов для семейств моделей. В одном парном сравнении на том же синтетическом WAV и том же промпте:

| Модель | По умолчанию | Минимально допустимое размышление |
|---|---:|---:|
| 3.6 Flash | 3,80 с; 277 thought tokens | 2,21 с; minimal |
| 3.8 Flash | 6,42 с; 349 thought tokens | 4,24 с; low |

Основной текст фразы сохранён, написание названия приложения варьировалось. В быстрых ответах API не сообщил число thought tokens. Каждый замер — один запрос; сначала шёл default, затем fast. Прогрев соединения, сеть и серверная нагрузка не контролировались, поэтому эти цифры не доказывают устойчивое ускорение на указанный процент. Новую сборку нужно сравнить на пользовательской диктовке.

EXE 1.1.2-beta собрана через `build.ps1` и запущена с тестовым профилем 3.8: hotkey включён, процесс работал через 10 секунд. Личный профиль и старые EXE не изменены. SHA-256: `AFC17DF6CE2189ED4AB16CD3BE89C8C508679C67CEF1449E82DA186FD868AF4C`.
