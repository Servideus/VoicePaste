# Модели по скорости — 1.1.4-beta

Меню содержит модели с медианой менее 5 секунд по [бенчмарку](../benchmark/2026-10-04/report.md). Для Flash Lite 3.5 использованы девять запросов, для Transcribe — семь успешных verbatim, для остальных — первый круг из трёх запросов. Это исторические замеры, не обещание текущей задержки.

| Порядок | Модель | Медиана, с |
|---|---|---:|
| 1 | Gemini 3.5 Transcribe — verbatim | 1,96 |
| 2 | Gemini 3.5 Flash Lite | 2,37 |
| 3 | Gemini 3.6 Flash | 2,86 |
| 4 | Gemini Flash Lite Latest — alias | 2,90 |

3.6 оставлена по критерию скорости пользователя, несмотря на ошибки качества в тесте. Flash Lite Latest — плавающий alias, в тесте указывал на 3.5 Flash Lite. Новая установка по-прежнему выбирает 3.5 Flash Lite. Сохранённая доступная модель сохраняется; удалённый из меню выбор при загрузке заменяется на 3.5 Flash Lite.

Transcribe использует REST Interactions API с `mode: {"type": "verbatim"}`, `language_codes: ["ru-RU"]` и `store: false`. Он сохраняет произнесённые повторы и слова-паразиты; автоматическая очистка smart отключена. [Проверка настроек](../benchmark/2026-10-04/transcribe-settings/report.md) обнаружила пропуски целых фраз в smart. В текущем проекте сервер сообщил ограничения Free Tier: 3 запроса в минуту и 25 в день; квоты могут изменяться.

Для 3.5 Flash Lite, 3.6 Flash и Flash Lite Latest используется thinking minimal. Transcribe не поддерживает thinking. Ограничения токенов для обрезки ответа не добавлены.

Потоковый Live API в эту сборку не включён. Полный сценарий новой сборки с голосом пользователя и вставкой требует пользовательской проверки. Доступность Free Tier зависит от модели и проекта; на проекте с биллингом запросы могут быть платными. Официальные документы: [Transcribe](https://ai.google.dev/gemini-api/docs/transcribe), [цены](https://ai.google.dev/gemini-api/docs/pricing).

После [проверки пользовательской записи](performance.md) по просьбе пользователя удалены 3.5 Flash, 3 Flash Preview, 2.5 Flash и 2.5 Flash Lite. Порядок оставшихся моделей сохранён. Числа в меню относятся к первому синтетическому бенчмарку; на трёхминутной записи медианы составили 5,18 / 6,32 / 8,58 / 10,07 с соответственно.

## Автоматический резерв — 1.1.5-beta

При ошибке API, тайм-ауте или пустом тексте приложение сразу пробует следующую модель. Порядок: выбранная модель, затем следующие пункты меню и возврат к началу; каждая модель проверяется один раз на эту запись. Используется тот же WAV. Выбранная модель в настройках не меняется, следующая запись снова начинается с неё. Первый непустой ответ вставляется один раз.

При неудаче всех четырёх моделей показывается одна общая ошибка с причинами. Ответ не гарантирован при общих проблемах ключа, сети или квоты. Тайм-аут одного запроса остаётся 30 секунд; последовательный резерв может увеличить ожидание. Ошибка вставки не запускает новое распознавание. Резервная модель может иначе оформить текст: Transcribe verbatim сохраняет повторы и слова-паразиты.
